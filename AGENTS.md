# Repository instructions

- On Windows, prefer Git Bash for ordinary shell commands; select the configured Git Bash executable explicitly when selecting a shell.
- Prefer Python for non-trivial text processing and structured data. Use PowerShell only for Windows-specific tasks.
- Never commit or print real credentials, tokens, private configuration, logs, caches, or security scan reports.
- Use temporary simulated data for tests. Do not make real API requests or read/write Windows Credential Manager.
